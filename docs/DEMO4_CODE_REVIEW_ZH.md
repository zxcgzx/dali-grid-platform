## 需要保留的技术边界
1. 源码中没有一个可供网页直接使用的Chat Completions兼容服务实现；Gradio自身可能暴露的事件接口也不等同于本平台的结构化模型契约。拿到对方正式API协议后再适配。
2. 四节点题的题干只列出成本、容量、开关和网络连接，没有给出线路阻抗、电压或交流潮流方程。文件本身也没有确定的AC-OTS模型实现。因此该题可用于网络调度建模演示，不能直接证明905节点AC-OTS能力。
3. 发电成本单位是元/MWh，而出力为MW；题干没有明确调度持续时间或固定成本的计费周期。这些应作为待补充信息，不能偷偷补成1小时。
4. 代码默认请求生成Python/coptpy；论文四题要求MATPOWER。平台保留两种任务来源和代码框架，不做无说明的替换。
5. 两个推理函数接收history，但实际构造的模型输入只包含当前问题，不是完整多轮对话上下文。
6. --use_streaming 使用store_true且default=True，没有对应关闭开关；按当前参数定义，普通命令行选项不能选择非流式分支。该问题属于参考脚本本身，本次未改动原稿。

## 四节点示例：中文译文
这是一个小型电力系统的经济调度优化问题，目标是为由4个节点组成的网络寻找最低成本运行方案。节点1和节点2为发电站，发电成本分别为300元/MWh、500元/MWh，最大出力均为100 MW。节点3、节点4为负荷节点，分别需要50 MW、100 MW。

五条输电线路依次为：(1,2)、(1,4)、(2,3)、(2,4)、(3,4)。线路可以接通或断开；接通时允许双向潮流，产生固定连接成本，并受最大输电容量约束。五条线路的固定成本依次为50元、50元、50元、150元、50元，最大容量依次为50 MW、50 MW、100 MW、100 MW、100 MW。需要确定各发电机出力、各线路开断状态及各线路潮流，使总运行成本最小。

这里未补充原题没有给出的时长、损耗、阻抗和电压条件；实际建模前应澄清。

## 药丸示例：中文译文
某实验室有1000单位药物原料，可生产大药丸和小药丸。每颗大药丸需要3单位药物原料和2单位填充材料；每颗小药丸需要2单位药物原料和1单位填充材料。实验室至少要生产100颗大药丸。由于小药丸更受欢迎，小药丸必须占全部药丸数量的至少60%。应分别生产多少颗，使填充材料总用量最少？

原文没有明确是否必须耗尽1000单位药物原料，翻译保留这一不确定性，不擅自改成等式。该例仅保存在对接文档，不放入电网业务题库。
