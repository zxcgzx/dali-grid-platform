# V0.5 地图与环节可视化：九模块归类

本轮用户要求：实现地图及各环节可视化，大框架沿用之前版本，功能放回已有模块。
本版保留北大红科研布局、三家Logo一上两下和原九个主导航，不另立“地图平台”或第二套流程导航。
功能基线：V0.4完整交付包；不使用本机中途写入版本作为终版。

| 原模块 | 本版归类与新增可视化 | 数据依据 |
|---|---|---|
| 工作台 | 地图概览、条件/版本/数据/静态阻断统计、下一步入口、六阶段总览、最近记录 | 当前工作包状态 |
| 需求理解 | 原文→拆分/API提取→人工确认图、条件核对数量及分布 | 已保存条件和逐条确认记录 |
| 动态建模 | L1—L4中文题库、参数/变量/目标/约束规模、版本谱系、父版本差异统计 | 当前模型与真实版本列表 |
| 数学模型 | 逐项审核进度、需求→模型分组关联图、点击原文追溯 | 人工保存的条件关联，不推断数学等价性 |

## 地图操作

首页“打开完整地图”进入结果分析。支持区域/母线/支路/机组搜索、状态筛选、图层开关、对象详情、拖拽平移、滚轮及按钮缩放、复位、聚焦、大图模式和SVG导出。

- 地理地图使用现有DataV大理州参考边界（12个子区域），保持原始来源说明。不是正式电网地理台账。
- 只有母线具有合法经纬度，且数据coordinate_system与底图坐标系相同，才叠加设备；未知或不一致时不自动转换。
- 没有坐标的数据可以显示电气拓扑。布局坐标由页面计算，只表示输入连接关系，不当作设备真实位置。
- 支路状态1、0、未提供分别使用在役、停运、未知样式。容量显示其输入单位；不把额定容量当作本次潮流。
- 四节点展示样例来自已提供demo_4.py题干，独立于任务数据，只查看、不绑定、不修改模型。明确显示“独立展示样例”。
- 拓扑最多绘制2000母线及5000支路，较大数据仅展示该上限；原始数据不被截断或改写。
- GeoJSON导入只接收Polygon/MultiPolygon，最多2000区域、200000坐标点和5MB。
- SVG导出保留来源和“未求解”提示。

## 流程展示规则

统计数字只取当前任务，未建立记录时显示0、待处理或未执行。页面跳转不改变完成状态。
需求、数据、审核发生变化时，当前/历史判断跟随V0.4版本约束。规则通过不解释为数学/物理正确性证明。
“过程记录”的事件时间轴回放只展示已有事件，不恢复历史业务状态、不执行操作、不调用API。

## 本轮未扩大范围

未加入真实求解、加速算法、实时电网控制、虚构潮流、虚构设备地理位置、假风险等级。
API设置继续由用户填写；本轮不部署大模型，不使用付费模型接口。
