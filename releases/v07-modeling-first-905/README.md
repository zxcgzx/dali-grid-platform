# 运行方式智能调整平台A V0.7

## 启动

双击 `启动平台.bat`，默认打开 `http://127.0.0.1:8770`。平台支持本机离线运行，不依赖外部CDN。

## 工作流程

自然语言指令 → L1—L4判级 → 模型规格与方程确认 → 分层校验 → 独立求解黑盒 → 大理地图与结果 → 课题3风险评估和协商。

模型规格采用 `M={ω, Δπ, s, R}`。支持AC-OPF/DC-OPF、OTS、机组出力调整、机组启停、目标与约束组合、版本比较和模型导出。

## 数据口径

唯一数据为905母线、237机组、1000支路。母线按原始BUS_I编号，支路按行号L，机组按行号G。相角单位为rad，基准容量100 MVA。输入断面为单断面；多时段复制仅用于单断面演示。

## 求解与接口

本机负责建模、校验和模型构建检查；优化求解通过独立黑盒服务调用IPOPT、COPT或Gurobi，也可导入已有AC-OTS结果。课题2测点/模型、课题3风险/Reward、铮昊动态建模与幻觉处置方法均在接口管理页配置。
