# 运行方式智能调整平台A

本目录为已同步到本机的 V0.5.1 A 版，保留九模块、地图、三家 Logo、中文题库和 API 接入。平台标题统一为“运行方式智能调整平台A”；大理作为实际地图区域和案例来源仍保留。

**当前启动方式优先于下方旧版说明：** 双击项目根目录或本目录的“启动平台.bat”，以及本目录“启动完整示例.bat”，均启动 `serve_demo.py`。默认地址 `http://127.0.0.1:8766`。需要现有 Python 3.11、NumPy、SciPy；不部署大模型、不新增商业求解许可。API最后自行填写。

工作台 → 打开四节点贯通示例 → 载入已核定数值（不调用LLM）→ 校验参数并编译数学模型 → 确认此版数学模型 → 优化求解 → 运行本机真实求解 → 结果分析。

真实语义解析时，填写模型API后改用“调用模型API解析”。已核定参考参数与API来源在界面分开标注。限定案例采用无损运输网络；不证明实际电网AC-OTS或N−1安全。

旧版本位于相邻的 `v05-visualization`，未覆盖。新部署的验证证据在 `artifacts/platform-a`；打包时附带的旧验证报告仅对应当时的历史版本。

## API与求解

在“数据与模型→模型/课题接口”填写。主模型和课题2模型采用Chat Completions兼容格式，业务接口沿用V0.4契约。

生成代码只展示或语法解析，不执行。求解页只提供少量选项、资料准备状态和交接包，不提交计算。
