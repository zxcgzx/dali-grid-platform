# V0.5 使用与演示

## 启动

Windows双击“启动平台.bat”，需要Python 3.10+。也可以 `python serve.py`，默认地址为 `http://127.0.0.1:8765`。这只是网页与API网关，不部署模型。
端口占用时运行 `python serve.py --port 8766`。直接打开index.html可以离线查看地图及多数界面，但API网关需要启动脚本。

## 推荐查看顺序

1. 工作台：查看地图概览与当前任务状态，主导航仍是原九项。
2. 结果分析：地理地图→搜索区域→点击属性→放大/平移/复位→大图模式。
3. 切换“电气拓扑”，选择“四节点展示样例”：查看四母线五支路和机组；关闭支路图层后再打开；搜索L12查看容量与端点。
4. 需求理解/动态建模：载入L1—L4任一中文题，逐条确认后使用“加载演示模板”（不填API也可演示）。
5. 数学模型：逐项确认并保存需求关联，展开需求关联图；关联图点击可追溯原文。
6. 模型校验：执行静态检查，图表将随真实规则结果更新；点击分类筛选。
7. 风险评估：按原V0.4方式查看/导入/调用风险意见、接受或拒绝，形成候选版本。
8. 结果分析→流程总览或过程记录：查看各模块当前状态和事件回放。

模板、测试服务和真实API的来源保持区分。事件回放不重新执行步骤，地图样例不绑定任务。
API最终在“数据与模型→模型/课题接口”填写。详见V04_API_CONTRACTS.md；本次保留该契约。

## 地图接入真实数据

在数据与模型导入并绑定标准JSON或CSV。拓扑需要buses、branches与generators；地理叠加还需要母线lon/lat和明确的coordinate_system。没有坐标时只显示连接关系。
本项目没有真实变电站坐标表，因此不会预填或虚构大理实际设备位置。

## 测试

`node tests/visual-v05.mjs`：默认使用Chromium内存文档渲染、自有HTTP网关测试和API/存储测试替身。不开外部付费接口，不能据此宣称真实专业服务联通。
`node tests/native-http-v05.mjs`：在本机Chrome/Edge中实际从自有HTTP服务加载，测试资源、导航及地图，不调用外部API。需要Node支持WebSocket，浏览器路径可用TEST_BROWSER指定。
